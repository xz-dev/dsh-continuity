# dsh-continuity

Port of [pi-continuity](https://github.com/xz-dev/pi-continuity) 0.2.0 for DSH 0.1.7-rc.2 and dsh-TUI 0.11.1. MIT, Copyright Xiangzhe. This port dynamically clones DeepSeek's MIT-licensed, pinned [`standard` preset declaration](https://www.npmjs.com/package/@deepseek-ai/dsh-web-app) and swaps its isolated compaction engine. No DSH core or daily user profile is modified by this repository. Full source-to-seam ledger and differences: [BEHAVIOR.md](BEHAVIOR.md).

Install into TUI profile from packed release: `dsh plugin --profile tui add file:/absolute/path/dsh-continuity-0.1.0.tgz --ignore-scripts`. Package `dsh.bundle.patch` registers the continuity preset and selects it as registry default. Explicit `DSH_TUI_PRESET`, stored `/preset` choice, and existing sessions override the new default. Check `/preset` in TUI before daily use; it should show `Continuity（默认） ✓`. The clone uses official Web `standard` declaration, which can differ from an independently customized TUI `standard` preset. Review the loaded preset's tool list and permissions before relying on it. Rows the profile replaces with its own plugins can be switched off in the clone with the `disable` config (row ids at any depth), for example `disable: [tool-web, tool-todo]` when dsh-web-access and dsh-todo-audit provide `web_search`/`todo`; an unknown id fails preset registration.

`/continuity` commits six-field continuity summary without waking the model; `/continuity continue` explicitly wakes after a successful commit. `/compact` stays native. Automatic threshold and overflow use DSH's existing policy with continuity extraction; ordinary extraction failures fall back to DSH's native summarizer and **lose source-verified quote guarantees**. User quotes are selected, bounded exact spans, not complete or validated instructions. No credentials should be placed in conversation on assumption compaction removes them.

The Pi above-editor progress widget, exact `details.continuity` metadata, native file-ops merge, multi-request usage attribution, and hidden continuation display are not ported; see gap rows in BEHAVIOR.md. Mechanically tested with `node --test test/`; actual model quality and multi-compaction reload need real-model evaluation. DSH plugin dependencies are exact pinned; never point this repo's `node_modules` at shared DSH runtime before `pnpm install`.
