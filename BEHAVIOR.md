# Continuity parity ledger

Target: Pi `pi-continuity` 0.2.0, user `~/.pi/agent/settings.json` lists its Git package and sets `compaction.remoteEnabled: false`; no continuity-specific config file. DSH/dsh-TUI pinned to 0.1.7-rc.2 / 0.11.1. Status describes actual mechanics, not model quality. **Partial parity: gaps below remain.**

Chosen integration: clone the pinned official `standard` preset declaration (`@deepseek-ai/dsh-web-app/presets/standard.patch.yml`) and replace *only* its isolated `compaction-basic` row. Host-level compaction is disabled by TUI's patch (`dsh-tui/cordis.patch.yml:97-108`); a host replacement would never reach preset agents. `dsh-continuity` registers `continuity` in `ctx.agentPresets` (`dsh-agent-preset-registry/lib/index.js:500`) and the bundle changes its default to `continuity`. DSH `BasicCompactionEngine.summarize` is overridable (`dsh-compaction-basic/lib/index.js:899-904`), leaving automatic threshold/overflow, retained tail, cancellation, lock and commit with DSH. Manual `/compact` stays native: our engine detects standalone `compaction/start` and delegates to basic unless `/continuity` explicitly requested it. On ordinary extraction failure, `super.summarize` handles native fallback; cancellation never falls back. This does **not** replace Pi's scheduling/threshold policy with Pi's policy.

Limits: non-user contexts/tool results never enter quote catalogue. A selected quote may still contain sensitive data; source hashes prove span identity, **not authorship or safety**. Raw model errors and session text never enter plugin warning. DSH model metadata and reserved output can make a valid Pi case fall back natively; that fallback **does not promise source-verified evidence**. Static default applies to new TUI sessions only: explicit `DSH_TUI_PRESET` or previously saved `/preset` selection wins, and existing sessions retain old composition. Cloned official Web standard may differ from TUI standard plugins; compare preset rows before daily rollout.
